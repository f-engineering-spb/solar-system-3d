## 2. Что уже реализовано и работает (Архитектура решения)

### 🪐 2.1. Астрономическая модель и физика NASA
- **10 небесных тел + спутники**: Солнце, Меркурий, Венера, Земля (+ анимированная атмосфера с облаками + Луна), Марс, Веста, Церера, Юпитер, Сатурн (+ процедурная кольцевая система с затенением), Уран, Нептун, Плутон.
- **Два режима масштабирования**:
  - **Стандартный (логарифмический)**: наглядный обзор всей Солнечной системы на одном экране без потери видимости малых планет.
  - **Реалистичный (NASA 1:1)**: истинные астрономические единицы (AU), реальные радиусы, кеплеровские эллиптические орбиты с эксцентриситетом и наклонением.
- **Симуляция времени**:
  - Плавный ход планет с точными сидерическими периодами вращения вокруг Солнца и вокруг собственной оси.
  - Пуск / Пауза, реверс хода времени (назад в прошлое), слайдер ускорения (x1 – x100).
  - Запуск тестового фотона со скоростью света $c$ от центра Солнца к внешним планетам.
- **Инфо-карточка NASA**:
  - Выезжающая панель с подробными физическими характеристиками (диаметр, орбитальный период, эксцентриситет, дистанция от Солнца, соотношение к Земле, описание).
  - Кнопка фиксации осевого вращения (пауза вращения конкретной планеты для детального осмотра рельефа).
- **Зона обитаемости (Goldilocks Zone)**:
  - Визуализация границ зоны возможного существования жидкой воды вокруг Солнца.

### ☄️ 2.2. Комета Галлея (Реалистичная физическая модель)
- **Ядро кометы**: неправильная гантелевидная форма 15×8×8 км (по данным зондов Giotto и Vega).
- **Активные криовулканические гейзеры**: 3 струи пыли и газа, бьющие с освещенной стороны ядра в сторону Солнца.
- **Ионный хвост (GLSL Shader)**: физический плазменный хвост кометы с филаментами, направленный строго антисолнечно ($-\vec{r}_\odot$).
- **Пылевой хвост**: изогнутый веер пыли под давлением солнечной радиации с градиентом рассеяния.
- **Кома**: 1 200 частиц звездной пыли с турбулентным дрожанием в солнечном ветре.

### 🪨 2.3. Пояс астероидов
- **2 800 индивидуальных 3D-астероидов**:
  - 3 спектральных класса: С-тип (углистые хондриты), S-тип (силикатные каменистые), M-тип (металлические).
  - Случайное 3D-кувыркание каждого астероида вокруг собственных осей.
- **Церера и Веста**: выделены как ключевые объекты пояса с официальными текстурами NASA Dawn и кнопками быстрого фокуса в левом меню.

### 🖥️ 2.4. Интерфейс и навигация (Стиль Apple Frosted Glass)
- **Левый вертикальный док (50 px)**:
  - Выполнен в матовом стекле (`rgba(15, 23, 42, 0.78)`), тонкие серебристые рамки (`rgba(255, 255, 255, 0.14)`).
  - Активные состояния и кнопки оформлены в светло-сером эппловском стиле (`#e2e8f0` с контрастным графитовым значком `#0f172a`).
  - **Полностью удален брендинг FERO и оранжево-медный цвет (`#D6632B`)** — интерфейс строгий, монохромный, премиальный.
- **Очистка от дублирования кнопок**:
  - Удалена лишняя кнопка «✋ Лапа». В движке Three.js OrbitControls изначально:
    - **ЛКМ** — 3D-вращение со всех ракурсов;
    - **ПКМ или удержание Пробела** — сдвиг сцены (лапа/панорамирование);
    - **Колесико мыши** — зум.
- **Устранен баг зума при перетаскивании**:
  - Добавлен порог `wasMouseDragged`, исключающий ложные клики и резкое масштабирование на Солнце после перемещения неба.
- **Всплывающие меню**:
  - При наведении на планету в 3D: плашка с названием, типом и диаметром у курсора.
  - При наведении на кнопки левого меню: всплывающий тултип с цветным маркером без обрезания краями экрана (`#dock-floating-tooltip`).

## 3. Стек технологий для мобильной версии

* **Базовая технология**: **Capacitor.js 6+** (современная нативная обертка от Ionic Team).
* **Среда сборки**: Node.js v26.7.0, npm.cmd v11.19.0, Android SDK, Gradle 8+.
* **Графический движок**: WebGL (Three.js r128), аппаратное ускорение внутри Chromium WebView на смартфонах (Adreno / Mali GPU) со стабильными **60–120 FPS**.

## 4. Дорожная карта реализации Android-приложения

### Этап 1. Автономный Offline-бандл (Критично для мобильного приложения)
- [x] Перенести внешние CDN-скрипты (`Three.js r128`, `OrbitControls.js`) в локальную папку `vendor/`.
- [x] Локализовать текстуры планет (2K NASA maps) для работы по протоколу `capacitor://localhost/` или `file:///android_asset/`.
- [x] Проверить запуск проекта при отключенном интернете (все 19 ассетов верифицированы тестом `npm.cmd run test:offline`).

### Этап 2. Мобильный Touch-интерфейс и Safe Area
- [x] Жесты управления:
  - 1 палец: свободное 3D-вращение;
  - 2 пальца (щипок / pinch): плавный зум;
  - 2 пальца (параллельный сдвиг): панорамирование (лапа);
  - Трекинг `touchmove` для предотвращения ложных кликов по планетам после перемещения сцены.
- [x] Сенсорные зоны (Touch Targets): увеличение размеров кнопок до стандарта $\ge 44 \times 44$ px под пальцы рук на смартфонах.
- [x] Safe Area Insets: поддержка «челок», островков фронтальных камер и вырезов (`env(safe-area-inset-top)`, `bottom`, `left`, `right`).
- [x] Мобильная карточка объекта: трансформация правой панели в нижнюю шторку (Bottom Sheet) с индикатором перетаскивания и свайпом вниз для закрытия.

### Этап 3. Инициализация Capacitor и генерация Android-проекта
- [x] Создать `package.json` и установить зависимости:
  ```bash
  npm.cmd install @capacitor/core @capacitor/cli @capacitor/android @capacitor/app @capacitor/haptics @capacitor/status-bar
  ```
- [x] Инициализировать конфигурацию `capacitor.config.json`:
  - `appId`: `com.solarsystem.planetarium`
  - `appName`: `Солнечная система 3D`
  - `webDir`: `dist` (автоматическая сборка скриптом `scripts/build.js`)
- [x] Сгенерировать нативный проект Android Studio:
  ```bash
  npx.cmd cap add android
  ```

### Этап 4. Интеграция нативных возможностей Android
- [x] **StatusBar / NavigationBar**: Immersive Sticky Mode (`MainActivity.java` с `WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`).
- [x] **Haptics API (`@capacitor/haptics`)**: деликатный тактильный виброотклик смартфона при тапе на планеты и переключении кнопок.
- [x] **KeepAwake / Wake Lock (`navigator.wakeLock`)**: блокировка отключения экрана во время наблюдения за орбитами.
- [x] **Hardware Back Button**: обработчик физической кнопки / жеста «Назад» Android (закрытие карточки $\to$ возврат камеры к Солнцу $\to$ сворачивание приложения).

### Этап 5. Иконка и Splash Screen
- [x] Генерация набора адаптивных иконок (`mipmap-hdpi`, `mipmap-xhdpi`, `mipmap-xxhdpi`, `mipmap-xxxhdpi`, `mipmap-mdpi`) с изображением Сатурна и орбит.
- [x] Настройка Splash Screen с глубоким космическим фоном (`#000004`), звездами и бесшовным переходом в WebGL-сцену.

### Этап 6. Сборка APK и тестирование
- [ ] Сборка отладочного APK:
  ```bash
  # Вариант А: открытие проекта в Android Studio (рекомендуется)
  npx.cmd cap open android
  # В меню: Build -> Build Bundle(s) / APK(s) -> Build APK(s)

  # Вариант Б: сборка через консоль Gradle (требуется установленный JDK 17 в JAVA_HOME)
  cd android && .\gradlew.bat assembleDebug
  ```
- [ ] Результат: готовый файл `app-debug.apk` для установки на смартфон через USB / Telegram.
- [ ] Тестирование производительности (FPS, стабильность памяти при переключении текстур).
