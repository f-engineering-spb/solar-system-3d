## 3. Текущее архитектурное состояние проекта

### 🪐 3.1. 3D-движок и сцена (`index.html`)
- **Three.js r128 + OrbitControls** (загружаются стабильно).
- **10 небесных тел + Луна + Комета Галлея + 2 800 астероидов**:
  - Солнце, Меркурий, Венера, Земля (+ атмосфера + Луна), Марс, Веста, Церера, Юпитер, Сатурн (+ кольца с тенью), Уран (+ кольца), Нептун, Плутон.
  - Комета Галлея (3D ядро, джеты, плазменный хвост, пылевой веер).
- **Масштабы**:
  - Стандартный (логарифмический обзор всей системы).
  - Реалистичный NASA 1:1 (астрономические единицы AU, кеплеровские эллипсы, наклонения).
- **Управление**:
  - Левый док (50px, Frosted Glass, стиль Apple).
  - Карточка NASA (справа на ПК, выезжающая снизу шторка на смартфоне).
  - Нижняя панель управления временем (Пуск/Пауза, реверс, слайдер скорости x1–x100, фотон $c$).

### 📱 3.2. Нативная обертка Android (Capacitor 8)
- Идентификатор: `com.solarsystem.planetarium`.
- Название: `Солнечная система 3D`.
- Сборка: Облачный CI/CD на GitHub Actions (`.github/workflows/build-apk.yml`) с JDK 21, Gradle 8.14, SDK 35.
- Нативные фичи: Immersive Sticky Fullscreen, WakeLock, виброотклик Haptics, обработка кнопки «Назад».

## 4. Задача для следующего этапа (в новом чате)

**Цель**: Улучшить удобство взаимодействия с планетами **строго внутри `index.html`**:
1. **Удобный захват**: улучшить выбор планет кликом мыши на ПК и тапом пальца на смартфоне.
2. **Фокус без потери планеты**: сделать так, чтобы при осмотре выбранной планеты она не улетала за пределы экрана при ее орбитальном движении.
3. **Масштабирование**: плавный и удобный зум как на компьютере, так и на телефоне.
4. **Управление вращением**: понятный и доступный способ останавливать осевое вращение планеты (чтобы рассмотреть рельеф) и возобновлять его.

> **Важно**: Все эти задачи должны решаться **пошагово, по одной за раз**, без ломки текстур и без отключения правой кнопки мыши (лапы).
